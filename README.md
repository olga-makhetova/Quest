# Текстовый квест на Java Servlet

Веб-приложение с текстовым квестом — пошаговой игрой, где игрок принимает решения и движется по цепочке карточек к победе или поражению.

## Как играть

Игрок попадает на стартовую карточку с вопросом и несколькими вариантами ответа. Каждый выбор ведёт к следующей карточке. Игра заканчивается, когда игрок достигает карточки с победой или поражением. Статистика побед и сыгранных партий сохраняется в сессии.

## Стек технологий

- **Java** — основной язык
- **Java Servlet API** — обработка HTTP-запросов
- **JSP** — отображение страниц
- **JUnit 5** — юнит-тестирование
- **Maven** — сборка проекта

## Запуск

1. Собрать проект:
   ```bash
   mvn package
   ```
2. Развернуть полученный файл `quest.war` на сервере (например, Apache Tomcat).
3. Открыть в браузере:
   ```
   http://localhost:8080/quest/go
   ```

## Запуск тестов

```bash
mvn test
```

## Как устроена модель

Игра состоит из карточек (`Card`). У каждой карточки есть вопрос, список ответов и состояние:

| Состояние | CSS-класс | Описание |
|---|---|---|
| `NORMAL` | `quest-normal` | Обычная карточка с выбором |
| `WIN` | `quest-win` | Конец игры — победа |
| `LOSE` | `quest-lose` | Конец игры — поражение |

Каждый ответ (`Answer`) содержит текст и id карточки, на которую он ведёт. Сессия хранит текущую игру и счётчики `gameCount` / `winCount`.
